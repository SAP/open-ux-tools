# Step 1: Database Tables

Create 4 tables (2 active + 2 draft). All must activate before Step 2.

## Directory/Root Table (e.g., `ZTRVL_REQ`)

**Key fields**: 
```abap
key client : abap.clnt not null;
key travel_request_uuid : sysuuid_x16 not null;
```

**Business fields**: 
```abap
travel_request_id : abap.numc(10);
employee_name : abap.char(80);
// ... other descriptive/business fields
```

**Admin fields**: 
```abap
created_by : abp_creation_user;
created_at : abp_creation_tstmpl;
last_changed_by : abp_lastchange_user;
last_changed_at : abp_lastchange_tstmpl;
local_last_changed_at : abp_locinst_lastchange_tstmpl;
```

---

## Hierarchical Child Table (e.g., `ZTRVL_ACT`)

**Key fields** (CRITICAL - composite key):
```abap
key client : abap.clnt not null;
key activity_uuid : sysuuid_x16 not null;
key travel_request_uuid : sysuuid_x16 not null;  // Foreign key to root
```

**Hierarchy fields** (MANDATORY):
```abap
parent_activity_uuid : sysuuid_x16;  // Self-reference to parent
sibling_order_number : abap.int4;    // Ordering within same level
```

**Business fields**: 
```abap
activity_id : abap.numc(10);
activity_name : abap.char(80);
location : abap.char(50);
activity_type : abap.char(20);
// ... other descriptive fields
```

**Admin fields**: Same as root table

---

## Draft Tables (e.g., `ZTRVL_REQ_D`, `ZTRVL_ACT_D`)

**⚠️ CRITICAL Field Naming**: All lowercase, no underscores
- **NOT** camelCase like `TravelRequestUUID` 
- **NOT** snake_case like `travel_request_uuid`
- **Pattern**: Remove underscores and lowercase everything from CDS view names

### Root Draft Table (`ZTRVL_REQ_D`)

```abap
@AbapCatalog.enhancement.category : #EXTENSIBLE_ANY
define table ztrvl_req_d {
  key mandt : mandt not null;
  key travelrequestuuid : sysuuid_x16 not null;
  
  travelrequestid : abap.numc(10);
  employeename : abap.char(80);
  // ... other fields (all lowercase, no underscores)
  
  createdby : abp_creation_user;
  createdat : abp_creation_tstmpl;
  lastchangedby : abp_lastchange_user;
  lastchangedat : abp_lastchange_tstmpl;
  locallastchangedat : abp_locinst_lastchange_tstmpl;
  
  "%admin" : include sych_bdl_draft_admin_inc;
}
```

### Child Draft Table (`ZTRVL_ACT_D`) - **Both UUIDs must be keys**
